标定步骤

O 点是摄像头地面投影的坐标原点，通常不在画面内（在镜头正下方、画面外）。无需在画面上点击 O，只需标定能看见的地面点。
  1. 1. 抓拍或上传监控画面
  2. 2. 在地面用卷尺从 O 点量出距离（如 5m、10m、15m、20m）
  3. 3. 在画面上点击该地面位置，输入实测距离
  4. 4. 建议加左右横向偏移点提高精度
  5. 5. 至少 4 个点后保存
